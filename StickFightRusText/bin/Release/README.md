# Этот мод сделан для удобства и использования в публичных лобби.
Чтобы вам было удобнее писать и читать русские сообщения без мороки понимания того полу-англиского русского который обычным смертным приходиться читать.

# Совместимость с другими игроками.
По дефолту, сообщения в которых есть русские символы будут отображаться другим как "[RuText Mod] {сообщение но только на ломанном русском чтобы избежать квадратов и оставить читаемость}"
Но, если у кого то в лобби уже есть этот мод, то можно использовать чат-команду (через # а не /) чтобы отметить этого игрока, после чего именно тому игроку сообщения будут видны чистой кириллицой. (#yrutxt = отметить жёлтого; #brutxt = отметить синего; #rrutxt = отметить красного; #grutxt = отметить зелёного). Если отмеченный игрок уйдёт, и зайдёт новый того же цвета, то отметка НЕ пропадёт.
## ===============
Если в лобби есть русский человек без этого мода, и вы не хотите читать его ломанный русский, то можно использовать чат-команду (через # а не /) чтобы отметить этого игрока, после чего его ломанный русский будет переводиться в кириллицу на автомате. (#yrus = отметить жёлтого; #brus = отметить синего; #rrus = отметить красного; #grus = отметить зелёного). Если отмеченный игрок уйдёт, и зайдёт новый того же цвета, то отметка НЕ пропадёт.

Повторное помечивание обнулит метку.

# Другое
Этот мод также добавляет поддержку кириллицы к никнеймам игроков. Крутяк.
Ни сами чат команды, ни текст который выводится после выполнения не видны другим игрокам.
Отправивь в чат "#rutext_resettags" вы обнулите все пометки.
Отправивь в чат "#rutext_toggleprefix", вы можете переключать начало дефолтный сообщений между полным "[RuText Mod] " и коротким "[R: ".
